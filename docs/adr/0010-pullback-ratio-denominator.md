# 「回调缩量」的分母取上涨段最大量，而非均量

`volume_contraction` 的缩量倍数定义为 **回调段均量 ÷ 上涨段「最大」量**，而不是直观的「÷ 上涨段均量」。这个取舍当初是拿九个样本定下的，没有记录；本期用 1,109 笔真实成交回头检验，发现**过半成交按其直觉读法根本不缩量**。本 ADR 记录这个已知偏差：**保留现口径，同时明确它不得被读成「回调比上涨安静」**。

## 九个样本是拟合，不是验证

当初的理由写在该函数的文档里：用**均**量作分母时，九个样本给出 0.51~2.30（**中位 1.08，即「回调期与上涨期一样活跃」**）；换成**最大**量后是 0.19~0.41（中位 0.32）。于是取最大值。

问题在于这一步的实际含义：那九个样本在均值口径下**本来就不显示缩量**。当时的处理是把指标换成最大值口径，使样本看起来像缩量，而不是接受「这条条件在这九个样本上不成立」。九笔样本不足以定下一个判据的分母，而这次改动没有任何 ADR 记录，故后来者只看到「缩量倍数 ≤ 0.5」这个门槛，看不到它度量的是什么。

## 回头检验（2026-09-15）

口径：v10 全市场记录（8,601 笔 / 2,315 标的）均匀取 300 个标的，复算出 1,109 笔；观测点取**下单那一根**（成交在次根开盘，故成交日的前一交易日），价格用后复权、与筛选器同一管线。

| | 中位 | 90% | 均值 |
|---|---|---|---|
| 过滤器读数（回调均量 ÷ 上涨**最大**量） | 0.370 | 0.474 | — |
| 直觉读数（回调均量 ÷ 上涨**均**量） | **1.044** | 1.966 | 1.226 |

- **53.0%（588 / 1,109）的成交，回调段均量 ≥ 上涨段均量**——按直觉读法即「完全没缩量」，而它们全部落在 ≤ 0.5 的门槛之内。
- 上涨段「最大量 ÷ 均量」的中位数是 **2.95 倍**。分母由均值换成最大值会让这个指标普遍缩小约三倍，故 `≤ 0.5` 实际上放掉了大多数候选。

触发这次复核的个案：`sh601601` 2026-01-21（成交于 01-22 开盘，随后 −4.51% 止损离场）。过滤器读数 0.466（过），直觉读数 1.163（不缩量）。分母是上涨段里单日最大的 2025-12-05，量能是上涨段其余各日的 **2.63 倍**；相对那一根，回调期的一切都显得「缩」了。

## 决策

1. **保留现口径**（最大量作分母、门槛 0.5）。理由是它已被 v8/v9/v10 三轮全市场回测端到端验证过；换分母不是等价改写——**会砍掉约一半候选**，必须重定门槛并重跑对照，不能顺手改。
2. **明确它度量的是什么**：`volume_contraction` 回答的是「**相对那段上涨里的单日爆量**，回调是否萎缩」，**不回答**「回调是否比上涨安静」。后者按均值口径读，而过半成交并不满足。
3. **两条量能条件不是独立证据**。同一根爆量既能把「上涨放量」撑过线（它在放量倍数的分子里），又能把「回调缩量」撑过线（它在缩量倍数的分母里）。故它们同时成立时，读作「这段行情有一根显著爆量」比读作「量价配合健康」更准确。

## Considered Options

- **分母改为上涨段均量、门槛重定**：更贴近直觉，也更能咬人（约一半候选会被砍掉）。但它是**判据的实质改动**，需要新的门槛（如 ≤ 1.0 或 ≤ 0.8）与一轮全市场对照才能定；本期未做。
- **两条读数都要求（最大值口径 且 均值口径）**：最保守，但等于把「缩量」改成「比上涨安静」，比选项一更严，且同样需要重跑。
- **不改代码、只记录**（**本 ADR 所选**）：判据的收入端（选出哪些标的）与支出端（回测结果）都已量化，改动的证据链还不完整——先把这个偏差说清楚，等有对照数据再决定。

## Consequences

- 阅读 `volume_contraction` 的判定结果时**不得**把 `≤ 0.5` 读成「回调缩量明显」。若要用这个直觉，须另算「回调均量 ÷ 上涨均量」。
- 未来若要重定这个分母或门槛，**必须重跑全市场对照**；不能据「更符合直觉」而改。
- `volume_structure` 的另外两个比值不受影响：放量倍数的分母是起涨前基准均量（与上涨段自身无关），顶部比值两边都是均值。
