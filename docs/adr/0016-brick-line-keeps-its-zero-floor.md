# 砖型图照字面保留公式的 0 底截断，不做「未截断」的美化

砖型公式的末句是先减 4、**再与 0 取大**。于是接近底部时砖型图会连续多根为 0，图上既不画红砖、
也不画绿砖。本 ADR 记录：**保留这个截断**，红砖/绿砖的判定与砖的大小都由这条被截断后的线算出。

## 为什么不「顺手改成未截断」

未截断的中间量是一条连续曲线，砖的大小在底部不会撞上平台，看上去更干净——而这正是任何后来者
都会想改的一处。代价在另一头：红砖/绿砖与砖的大小，是从**图上画出来的砖**读出来的，而画的就是
截断后的值。换成未截断，等于换一条线回答同一个问题，而**看名单看不出这件事**。

## 代价（认下的）

- 底部区域连续为 0 ⇒ 那段**既无红砖也无绿砖**，故「前一天绿砖、当天红砖」这个过滤条件
  在那里**结构上不可能成立**，与标的当天的强弱无关。
- 一根从 0 抬到 3 的红砖，与一根 8→11 的红砖，被判为**同高**（大小都是 3）。故排序因子一
  在底部附近被**削平**，它在那里分不出「刚刚抬头」与「走得急」。
- 削平有多大**尚未度量**。要量它，得对全市场统计「红砖里从 0 起跳的占比」与这些格子上的
  因子值分布。

## Considered Options

- **保留截断**（本决策）：判据与图上所见一致；代价是底部平台，且这段的排序区分力弱。
- **用未截断的中间量算大小**：底部连续、区分力更强；代价是与图上不再是同一个东西，
  而「红砖」的含义会跟着变。

## Consequences

- 后来者看见「底部一堆 0」会想改，改之前必须先读这一条。
- 若将来要改，它是一次**口径变更**：过滤条件的成立域与排序因子一的分布都会变，
  故新旧名单**不可比**，得当成两条规则各自量。
