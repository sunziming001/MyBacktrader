# 数据缺口以「跳过」处理，禁止填充

遇到行情数据的缺失与异常，采取：缺失视为该标的当日不可交易并**跳过**；异常值（价格为 0、单日涨跌幅超出制度上限）**报错**。

## Considered Options

- **跳过 + 异常报错**（采纳）
- **任何缺口都硬失败**（否决）：停牌、次新股、数据商偶发缺行都属正常噪声，硬失败会让日常时间耗在修数据而非做策略。
- **插值 / 前向填充**（**禁止**）

## 决策

缺口只损失样本，填充会污染结论。**宁可缺，不可错。**

## Consequences

前向填充价格会凭空造出「没有成交的成交」，把错误悄悄埋进结论，且事后极难察觉——这类错误不会被净值曲线上的异常暴露出来，只会让回测结果偏乐观。因此填充不是「暂不方便」，而是明令禁止。

「单日涨跌幅超出制度上限」这一异常检测依赖 A 股涨跌停规则（见 ADR-0002）；异常与**正常涨跌停**必须区分，后者不是数据错误。

区分**停牌**与**退市**是这套纪律的实现要求：两者都表现为此后无新记录，但停牌是正常状态、退市是永久终止。

## 修订：停牌与退市**只能部分区分**（2026-09-12，票据 #9）

上面那句「是这套纪律的实现要求」需要**收窄**——实测表明它**只能部分做到**，而写成一个无条件的要求
会让人以为已经覆盖了。

**能判的**：**区间内停牌**（中间有缺口、其后恢复）。按全市场交易日日历数出缺失的交易日，报
「自 A 至 B 无成交、共缺 N 个交易日、已于 C 恢复」（`mbt.data.updates`）。

**判不了的**：**尾部空缺**（自某日起再无新记录）。它**在数据里同形**——既可能是长期停牌（A 股真实
存在停牌一年以上），也可能是退市。实测本机 5,898 只股票的尾部空缺分布：

```
0（最新）      5,549   94.1%
1–5 个交易日       6
6–20              6
21–60            12    ← 模糊区
> 60            325    ← 多为 1997–2002 的老退市股
```

那 325 只**大多是**退市股，但**没有依据**把它们与长期停牌分开：`.day` 不含上市日、退市日、重组
停复牌标记，也不含「G」标记；`hq_cache/base.dbf`（8,217 条）**无名称字段**，且退市代码**部分仍在
表内**（`000003`、`000015` 在；`000508`、`600625`、`600806`、`600001` 不在）——故「不在主表」
不是可靠的退市信号。

**决定**：尾部空缺**只报事实**（自 X 起无数据、共缺 N 个交易日），并**显式标注不可区分**；
**不引入阈值代理**（如「超过 N 天即视为退市」）。这与本 ADR「异常报错而非猜」的立场一致，也与
`mbt.data.anomaly` 拒绝用代理变量判停牌的既有做法一致。

**代价**：任何需要「这只标的是否已退市」的判断（例如严格成分股口径）在本项目里**做不到**，
必须显式登记为局限，而不是含糊过去。消除它需要数据源提供退市日期，仍属接入网络数据源那一类工作。

## 补记：实现结果与判据的一处订正（2026-09）

落地在 `mbt.data.anomaly`（`find_anomalies` / `require_no_anomalies`）。「价格为 0、K 线
不自洽」这两项在 `TdxDataSource._reject_anomalies` 解析时即报错；「越出涨跌停带」需要
按日期与板块查规则表、还要权息事件来解释跳空，故单独成模块。

### 判据订正：比**限价带**，不是比涨跌幅比率

「单日涨跌幅超出制度上限」这句表述**照字面实现是错的**。实测本机 16 只主板股票的 43,982
个相邻交易日里，日间变动超 10% 的有 460 次，其中 **444 次合法**：

- **四舍五入效应**：`11.26 × 1.1 = 12.386` 进位到 12.39，涨 10.04%；
- **收在涨停但盘中未锁死**：收盘价触限不代表涨跌幅恰好等于限幅。

故判据改为 `low/high` 是否越出由前收盘价算出的**限价带**，且限价一律走**十进制半进位**
到分（内建 `round()` 在二进制浮点上运算，恰好半分时会少一分）。在两种算法会分歧、且当日
确实触及限价的 38 个交易日里，市场**全部**落在十进制半进位一侧，无一例外。

该算法由撮合层与质检层**共用**（`mbt.rules.price.limit_price`），因为两处必须给出同一个
答案，否则「撮合时认为没触限、质检却报异常」这种自相矛盾迟早会发生。

### 归因：用除权除息事件解释跳空，而不是见到事件就豁免

除权除息日的限幅以**除权除息参考价**为基数，故那一天的合法区间整体下移。检查按「前一根
K 线之后、当根 K 线之前（含当根）」取**全量**事件，同日多条求和、跨日**链式**折算
（每一步的基数都不同）——跨 K 线的那一步很关键：长期停牌期间的权息事件在复牌日才体现为
跳空，只查当根 K 线会漏掉它们（实测 5 例长期停牌复牌日全靠这一步才归因正确）。若没有事件
而越界，或有事件但按其重算的带仍被越出，则报错。

只有**除权除息类**（类别 1）事件参与归因，与 ADR-0003 的价格复权口径一致。

### 检查落在数据层入口，不在回测入口

`load_market_data` 把「行情 + 权息 + 规则表」组合起来并在返回前强制检查，拿到返回值即证明
检查跑过。不放进 `run_backtest` 有两个原因：它只拿到一张价格表，无从判断跳空的性质；更
要紧的是，若它对着**后复权价**做同一次检查，权息事件会把复权已经抹平的跳空再折算一次，
**凭空造出假异常**（例：10 元 10 送 10，原始价次日 5.00、后复权两日都是 10.00，两者都合法，
但按事件重算的带是 [4.5, 5.5]，后复权的 10.00 就被判越界）。

### 已知误报源：制度空窗，而非判据错误

全市场实测（9,720 个文件、1,135 万根 K 线；实测于 2026-09-11）检出 761 处越界，**没有一处**是「无任何制度空窗
可解释」的坏数据；761 处全部落在规则表已声明的「有意省略 B 类」里：

- **序列前 5 根**（601 处）：新股上市初期不设涨跌幅；
- **北交所**（76 处，集中在 2021–2023）：本地 `bj/` 混存北交所与新三板，`920xxx` 的历史
  回溯到上市前的新三板挂牌期——那段时期只有 ±30%/±60% 的**盘中临时停牌**，没有硬性涨跌幅
  限制；
- **其余约 82 处**：股改复牌首日（上证交字〔2005〕7 号：股权分置改革实施后复牌首日不除权、
  不设涨跌幅限制，次一交易日起恢复）、重大资产重组/借壳复牌、退市整理期，以及缩股/债转股
  等**非除权除息类**公司行为（`gbbq` 类别 2 及以后，按 ADR-0003 不参与价格复权，故质检看
  不到它们）。这批未逐例定案——定案需要「上市日 / 退市日 / 重组停复牌标记」，而 `.day` 不含。

**结论**：该判据**不放过**坏数据（限价算错会在除权日与涨跌停日大面积误报，而实测误报密度仅
0.0067%），但**会误报**制度空窗。故它适合「报错让人看」，不适合无人值守的批量过滤——全市场
选股应在调用处捕获 `MarketDataError` 并把标的记为**存疑**，再人工抽查。逐条数字与分类见
`docs/research/tdx-halt-and-limit-representation.md` 结论五的补记。

所有误报源指向同一件事：缺少「那一天这只股票处于哪种制度之下」的信息。用停牌天数或价格
幅度之类的代理变量去猜，正是本 ADR 拒绝的模糊判据。
