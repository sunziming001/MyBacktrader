# 一期只使用本地通达信数据

数据来源在一期只用本机通达信 `vipdoc` 目录，不接入网络数据源（akshare / tushare / baostock）。数据访问层按 adapter 设计，为后续加入第二数据源留出接口。

## 决策

一期只吃本地数据。本地日线数据通过通达信客户端下载扩展（实测于 2026-09-12：`sh`/`sz`/`bj` 三市场日线共 **12,243** 个 `.day` 文件，其中 `sh` 6,023 / `sz` 5,868 / `bj` 352；`sh600000` 覆盖 1999-11-10 → 2026-09-11，6,388 根）。这个窗口是**可扩展**的——上文的文件数与年份只是当时的快照，不是上限。

引入第二数据源会立刻带来「两套复权口径、两套字段定义、不一致的退市处理」的一致性负担，在一期打通端到端管道之前不承担。

## Consequences

数据窗口的长度**不是**本项目的固定约束，它等于「本地通达信已下载的历史」，可通过客户端下载扩展，因此不设上限、也不作为已知局限记录。

真正无法覆盖的是**已被通达信清除的标的**。这一点**已在两类数据上分别实测确认**：

- **价格数据**：股票池按「当日存在有效数据」定义，退市前的历史天然纳入，但被清除的标的无法找回。
- **财务数据**：`gpcw` 各期均**不含退市代码**——1995 / 2005 / 2010 年文件中 100% 的代码在 2025 年仍然存在，而 600001、600806、002450、600485、000939 等退市代码在所有 147 期中**均不出现**。

因此**幸存者偏差同时污染价格与基本面两条链路**，且无法通过本地数据消除。此项作为已知局限显式记录，不得含糊：任何回测结论都不得声称已排除幸存者偏差。

数据层保持 adapter 可插拔，使「本地为主 + 网络补历史（含退市标的）」可以在以后加入而不触动上层。这是消除该偏差的唯一途径。

## 数据层必须判定品种

价格目录中**混存非股票标的**：实测 `vipdoc/sh/lday` 下前 3 位分布含 `600`(760)、`880`(656)、`603`(619)、`688`(617)、`881`(467)、`601`(228)、`113`(133) 等，其中 **`113xxx` 是可转债、`880`/`881` 是板块指数**。

因此「文件存在即纳入股票池」是错的。数据层必须按 **代码前缀判定品种**（股票 / 指数 / 可转债 / 基金），股票池只从判为「股票」的标的中构建。否则可转债与板块指数会混入选股结果——而这类污染在净值曲线与回测报表上**不会显现**，只会让结果失去意义。

财务数据的代码空间与价格数据**实测对齐**（`bj` 侧两边均为 `920xxx`），可直接关联，无需映射表。
