# 一期只使用本地通达信数据

数据来源在一期只用本机通达信 `vipdoc` 目录，不接入网络数据源（akshare / tushare / baostock）。数据访问层按 adapter 设计，为后续加入第二数据源留出接口。

## 决策

一期只吃本地数据。本地日线数据通过通达信客户端下载扩展至 **2015 年至今**（约 11 年、2800 余个交易日）；`sh`/`sz`/`bj` 三市场日线共约 9700 个 `.day` 文件。

引入第二数据源会立刻带来「两套复权口径、两套字段定义、不一致的退市处理」的一致性负担，在一期打通端到端管道之前不承担。

## Consequences

数据窗口的长度**不是**本项目的固定约束，它等于「本地通达信已下载的历史」，可通过客户端下载扩展，因此不设上限、也不作为已知局限记录。

真正无法覆盖的是**已被通达信从 `vipdoc` 清除的标的**：股票池按「当日存在有效数据」定义，退市前的历史天然纳入，但被清除的标的无法找回，由此产生的**幸存者偏差作为已知局限显式记录**，不得含糊。

数据层保持 adapter 可插拔，使「本地为主 + 网络补历史」可以在以后加入而不触动上层。
